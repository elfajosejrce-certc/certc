# CERTC Website

Responsive single-page website for ConceptEngineering Review and Training Center.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static file server.

## Publishing

The included GitHub Actions workflow publishes the repository root to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected.

## Content updates

- Main content and links: `index.html`
- Colors and visual styles: `styles.css`
- Navigation and animation behavior: `script.js`

The current site uses no external frameworks, fonts, or image dependencies.
