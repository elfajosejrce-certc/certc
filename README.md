# CERTC Website

Responsive single-page website for ConceptEngineering Review and Training Center.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static file server.

## Publishing

The included GitHub Actions workflow enables GitHub Pages and publishes the repository root automatically.

## Content updates

- Main content and links: `index.html`
- Colors and visual styles: `styles.css`
- Navigation and animation behavior: `script.js`

The current site uses no external frameworks, fonts, or image dependencies.

## Soil report builder

Open `soil-report/` to prepare an editable geotechnical soil investigation report. The form supports project and client details, investigation scope, soil profile rows, laboratory results, findings, recommendations, and professional sign-off. Drafts can be saved in the current browser, and the report can be printed or saved as an A4 portrait PDF. All entries and engineering interpretations require review against original investigation records by a qualified professional.
